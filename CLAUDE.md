# anything.sh

A self-modifying bash script website: a bash script that uses the Claude CLI to generate code that appends to itself.

## Project Structure

- Main component: `src/anything_sh.tsx` (React + Tailwind CSS)
- The scripts (`SCRIPT_FULL` and `SCRIPT_TERSE`) are embedded in the component and displayed to users

## Development

- `bun run dev` - Start development server
- `bun test` - Run tests
